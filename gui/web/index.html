Color scheme

Mode
Template set

A template set is the look: the widgets, bars, and chrome every module draws. What a set lacks comes from Themer Default.


      
Colors

      

      
A color of your own over the scheme's, in both modes: pick one, or Scheme to go back to the scheme's.

    

    

      
Fonts

      

        

        

        

      

      
The interface font goes to GTK, Qt, the window manager, and the browsers; the terminal font to the terminals, editors, and Qt's fixed font; the console font to the Linux console (vconsole.conf).

      
Rendering

      

        
        
        
      

      
Written to the GTK settings, xsettingsd, gsettings, and fontconfig, so every toolkit draws text the same way.

    

    

      
Icon theme

      

      
Set for GTK, Qt, xsettingsd, and gsettings; Firefox's toolbar takes its icons from it too. Below, the theme's own icons, found as GTK and Qt find them (the theme, the themes it inherits, hicolor).

      

    

    

      
Mouse cursor

      

        
        
      

      
Applied through the cursor module (the Xcursor default theme, XCURSOR_THEME and XCURSOR_SIZE, Xresources), the GTK settings, gsettings, and sway's seat.

    

    

      
Modules

      
Each module themes one program: turned on it writes that program's settings, turned off it removes them. Switches and options take effect at once.

      

    

    

      
Environment

      
Variables for the whole session, written to environment.d on apply, where login sessions and systemd user services read them.

      

      

    

    

      
Server

      
 themer-web is running at  (this page)
        

      

        on localhost; the server moves to a new port, and this page with it

      
themer-web is started and stopped by hand (here, in any front end's main menu, or themer server start), and stops by itself when no browser module (firefox, stylus) is on.

      
Stylus installs the userstyles from here and keeps them current through their @updateURL while the server runs. Each site, with its Install link, is under Modules, stylus.
